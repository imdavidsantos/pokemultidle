# Pokemultidle

Gerencie até 4 contas do [PokeIdle](https://pokeidle.io/app) em uma única janela.

## Como baixar

1. Acesse a página de [**Releases do Pokemultidle**](https://github.com/imdavidsantos/pokemultidle/releases/latest).
2. Na seção **Assets**, baixe o instalador ou o executável correspondente ao seu sistema operacional.
3. Após o download, abra o arquivo e siga as instruções para executar o Pokemultidle.
4. **Windows:** baixe o arquivo `.exe` disponibilizado na seção **Assets**. Se houver uma versão portátil, você poderá executá-la sem precisar instalar o aplicativo.

> **Importante:** baixe os arquivos da seção **Assets**. Não escolha `Source code (zip)` ou `Source code (tar.gz)`, pois esses arquivos contêm apenas o código-fonte do projeto.

## Recursos

- Gerencie até 4 telas, com o botão **+ Adicionar tela** e a opção ✕ para remover.
- **Modo foco:** amplie uma tela usando ⤢ ou as abas no topo e volte à visualização **Todas**.
- **Resolução simulada:** cada tela simula um monitor de 1920 × 1080, redimensionado para caber no painel.
- **Controles individuais:** mute, volume e zoom de 50% a 200% por tela, reload e boost.
- **Modo Boost:** a tela começa a simular como 500x900.
- **Sessões independentes:** cada conta mantém seu próprio login, salvo separadamente.
- **Renomear contas:** clique no nome da conta para alterá-lo.
